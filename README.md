Tic Tac Toe Game

Project Overview

A simple two-player Tic Tac Toe game developed using Python. Players take turns marking X and O on a 3×3 game board.

Features

- Two-player gameplay
- Interactive 3×3 game board
- Winner detection
- Draw detection
- Input validation
- Option to play again

Technology Used

- Python 3

How to Run

1. Install Python 3.
2. Download this repository.
3. Open the project folder in VS Code.
4. Run:

python tic_tac_toe.py
